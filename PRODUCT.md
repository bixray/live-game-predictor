# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Inferred for this first build: sports fans who want to explore likely game outcomes and understand which inputs affect a prediction.

## Product Purpose
Provide a usable football and basketball prediction dashboard. Success means visitors can scan a match slate, inspect a matchup's estimate, and understand the assumptions behind it.

## Positioning

This first version makes prediction inputs and calculations visible instead of presenting a bare pick. The data and model outputs are illustrative, not validated.

## Brand Commitments

The user chose the product name **Bixray's Live Predictor**. Existing data-demo notices remain explicit: the current site has no live feed.

## Operating Context
Visitors use a responsive web page to switch sports, search teams and competitions, filter match states, and adjust a home-advantage assumption while viewing a selected matchup.

## Capabilities and Constraints
- Static, dependency-free demo that can run from a local HTTP server and publish with GitHub Pages.
- Fixture, score, time, team-rating, prediction, and odds values are synthetic examples.
- No live sports-data or bookmaker provider is connected; no real prediction performance is claimed.
- Provider choice, credential handling, data licensing, and model validation remain open decisions.

## Evidence on Hand
No production data, provider integration, historical validation, or performance evidence is available. The included sample data is illustrative only.

## Product Principles
- Make demo or provider state unambiguous.
- Explain the inputs behind an estimate.
- Treat predictions as uncertain estimates, not guarantees.
- Keep core fixture browsing usable on mobile and with a keyboard.
